# Literature Survey

This folder contains the literature review conducted for the project.

## Purpose

The literature survey aims to analyze existing research related to:

- Cloud Maturity Assessment Models
- Digital Transformation in Rural MSMEs
- Cloud Adoption Frameworks
- Artificial Intelligence for Decision Support
- Explainable Artificial Intelligence (XAI)
- Decision Intelligence
- Cloud-Native Technologies
- MSME Digital Readiness Assessment

## Contents

This folder will include:

- Research papers (2022–2026)
- Summary of reviewed papers
- Comparative analysis
- Key findings
- Existing methodologies
- Identified limitations
- References

> The literature survey will be updated as more relevant research papers are reviewed.
